📖 О проекте Flask Blog

🎯 Цель проекта

Этот проект демонстрирует навыки работы с фреймворком Flask и сопутствующими технологиями. Реализован полноценный блог с системой аутентификации, постами, комментариями и тегами.

🛠 Используемые технологии

Backend
  • Flask - веб-фреймворк
  • Flask-SQLAlchemy - ORM для работы с БД
  • Flask-Login - управление сессиями
  • Flask-WTF - формы и CSRF защита
  • Flask-Migrate - миграции БД
Frontend
  • Bootstrap 5 - CSS фреймворк
  • Jinja2 - шаблонизатор
Инструменты
  • SQLite - база данных
  • pytest - тестирование

✨ Функциональность

  • Регистрация и аутентификация пользователей
  • Хеширование паролей
  • Создание, редактирование и удаление постов
  • Комментирование постов
  • Теги для постов
  • Поиск по постам
  • Пагинация
  • Счетчик просмотров
  • Черновики постов
  • Профили пользователей
